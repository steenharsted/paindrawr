# Import RedCap PainDraw JSON data

Reads JSON files generated by the RedCap *PainDraw* module and converts
them into a pdr_tibble (see
[`pdr_match()`](https://steenharsted.github.io/paindrawr/reference/pdr_match.md)
for the terminology).

## Usage

``` r
pdr_import_json(files)
```

## Arguments

- files:

  Character vector (or list coercible to character) of file paths.

## Value

A pdr_tibble (see
[`pdr_match()`](https://steenharsted.github.io/paindrawr/reference/pdr_match.md))
with one row per successfully file in `files` and columns `pdr_data` (a
pdr_list of pdr_drawings) and `id` (copied from `.id`). Non-existing
files give a warning and `NA` in `pdr_data`, with `id` derived from the
file name; files with invalid JSON give an empty
[`list()`](https://rdrr.io/r/base/list.html) and `NA` in `id`; `NA`
entries in `files` give `NA` in `pdr_data` and `id`. On invalid `files`
input, an empty [`list()`](https://rdrr.io/r/base/list.html).

## Details

Each input file is expected to contain a single pain drawing. Multiple
files can be provided and will be combined row-wise.

**Expected JSON structure**

The input JSON must conform to the following structure:

- A named list containing metadata for a single pain drawing, including:

  - `id` (character): unique drawing identifier

  - `v`, `w`, `h`, `units`, `ts`, `app`: version, canvas width, canvas
    height, units, timestamp and app name

  - `s`: stroke data

- `s` must be a data frame where each row represents a stroke and
  includes:

  - `strokeId`: integer stroke identifier (unique within drawing)

  - `drawInputType`, `tool`, `lineWidth`, `color`, `alpha`,
    `sprayRadius`, `sprayDensity`: stroke properties

  - `p`: list-column of coordinate matrices

- Each element of `p` must be an integer matrix with two columns:

  - column 1: x-coordinates

  - column 2: y-coordinates

**Transformation details**

- The metadata fields are renamed to the pdr_drawing elements `.id`,
  `.version` (`v`), `.width` (`w`), `.height` (`h`), `.units`,
  `.timestamp` (`ts`) and `.app`; `.file` is set to the file path. Other
  fields are dropped.

- Coordinates in `p` are converted into the `.points` tibble with
  columns `.index` (the position of the stroke in `s`), `.x` and `.y`.

- The y-axis is flipped using the drawing height (`.height`) so that the
  origin is in the lower left corner.

- The remaining stroke properties are stored in the `.strokes` tibble,
  with renamed columns: `strokeId` becomes `.index`, `drawInputType`
  becomes `.draw_input_type`, `tool` becomes `.tool`, `lineWidth`
  becomes `.tool_width`, `color` becomes `.color`, `alpha` becomes
  `.alpha`, `sprayRadius` becomes `.spray_radius` and `sprayDensity`
  becomes `.point_density`.

**Failure handling**

If `files` is not a character vector (or list coercible to one), or is
empty, a warning is given and an empty
[`list()`](https://rdrr.io/r/base/list.html) is returned. A file that
does not exist, or whose content is not valid JSON, gives a warning and
is kept as a placeholder row, so that rows stay aligned with `files`:
its `pdr_data` element is an empty
[`list()`](https://rdrr.io/r/base/list.html) and its `id` is
`NA_character_`. Downstream functions drop such placeholder rows with a
warning.

An `NA` entry in `files` is not a failure: its `pdr_data` element is
`NA` and its `id` is `NA_character_` (NA in, NA out).

A valid file without any strokes (`s` is empty) is not a failure: it
gives a drawing whose `.points` and `.strokes` are zero-row tibbles with
the usual columns.

## Examples

``` r
# Load a single file
json_file <- pdr_example_file("9_draw_zealand.json")
pdr_import_json(json_file)
#> # A tibble: 1 × 2
#>   pdr_data          id                                
#>   <list>            <chr>                             
#> 1 <named list [10]> PID4193-R9F-draw_zealand-E13885-I1

# Load multiple files (here, the same file twice)
pdr_import_json(c(json_file, json_file))
#> # A tibble: 2 × 2
#>   pdr_data          id                                
#>   <list>            <chr>                             
#> 1 <named list [10]> PID4193-R9F-draw_zealand-E13885-I1
#> 2 <named list [10]> PID4193-R9F-draw_zealand-E13885-I1

# Plot imported data
pdr_import_json(json_file) |>
  pdr_plot_xy(background_image = pdr_example_file("bg_zealand.png"))
```
