# Import PNG files as pdr drawings

Reads PNG files generated by custom software and converts them into
pdr_drawing elements (see
[`pdr_match()`](https://steenharsted.github.io/paindrawr/reference/pdr_match.md)),
so that the rest of the paindrawr pipeline can be used. The pixel data
is stored in the `.rgba` element. Since a PNG holds no stroke
information, `.points` and `.strokes` are empty tibbles with the
expected column types.

## Usage

``` r
pdr_import_png(
  files,
  background = NULL,
  background_tolerance = 0,
  id_from_filename = TRUE
)
```

## Arguments

- files:

  Character vector of paths to PNG files.

- background:

  Optional colour (anything
  [`grDevices::col2rgb()`](https://rdrr.io/r/grDevices/col2rgb.html)
  accepts, e.g. `"white"` or `"#000000"`) that marks the background of
  PNGs *without* an alpha channel (1 or 3 channels). Matching pixels get
  alpha 0; all others get alpha 1. Ignored for PNGs that already have
  alpha. If `NULL` (default), such PNGs are fully opaque. Note that
  drawn pixels of exactly the background colour cannot be distinguished
  from background.

- background_tolerance:

  Maximum absolute difference (0-1 scale, per channel) from `background`
  for a pixel to count as background. Default 0 (exact match). Increase
  to remove anti-aliasing halos, at the cost of also removing faint
  strokes.

- id_from_filename:

  Logical. If `TRUE` (default), `.id` is the file name without directory
  and `.png` extension. If `FALSE`, `.id` is `NA_character_`.

## Value

A pdr_tibble (see
[`pdr_match()`](https://steenharsted.github.io/paindrawr/reference/pdr_match.md);
as from
[`pdr_import_json()`](https://steenharsted.github.io/paindrawr/reference/pdr_import_json.md))
with one row per file and columns `pdr_data` (a pdr_list of
pdr_drawings, each containing `.id`, `.file`, `.version`, `.width`,
`.height`, `.units`, `.timestamp`, `.app`, `.points`, `.strokes` and
`.rgba`) and `id`. `NA` entries in `files` give `NA` in `pdr_data` and
`id`. Non-existing files give a warning and `NA` in `pdr_data`, with
`id` derived from the file name (if `id_from_filename`).

## Details

PNGs with fewer than four channels are converted to RGBA without loss of
information: grayscale (1 channel) is replicated to R, G and B with
alpha set to 1; grayscale + alpha (2 channels) is replicated to R, G and
B; RGB (3 channels) gets alpha set to 1. Indexed (palette) PNGs are
expanded to RGB(A) by
[`png::readPNG()`](https://rdrr.io/pkg/png/man/readPNG.html). Pixels
that are fully transparent are set to black (rather than transparent
white). The row order of `.rgba` is as returned by
[`png::readPNG()`](https://rdrr.io/pkg/png/man/readPNG.html) (row 1 is
the top of the image).

## Examples

``` r
if (FALSE) { # \dontrun{
pdr_tibble <- pdr_import_png(c("drawing_a.png", "drawing_b.png"))
} # }

# Import an example PNG (grayscale/RGB without alpha: opaque unless
# `background` is given)
pdr_import_png(pdr_example_file("bg_full_body.png"))
#> # A tibble: 1 × 2
#>   pdr_data          id          
#>   <list>            <chr>       
#> 1 <named list [11]> bg_full_body

# Treat white pixels as background (alpha 0)
pdr_import_png(pdr_example_file("bg_full_body.png"), background = "white")
#> # A tibble: 1 × 2
#>   pdr_data          id          
#>   <list>            <chr>       
#> 1 <named list [11]> bg_full_body
```
